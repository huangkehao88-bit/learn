# 🚗 3D 智能小车 · 深度强化学习(DQN)教程项目

> 一个 **3D 世界中的智能小车**，通过深度强化学习(DQN)学会自动追踪目标、避障。
> 全程用 **numpy 从零实现** 神经网络和 DQN 算法，并用 matplotlib 做 **实时 3D 可视化**。
> 本项目同时是学习 **Git / GitHub 代码管理** 的完整练习。

## ✨ 你能学到什么

| 领域 | 具体知识点 |
|------|-----------|
| **机器人** | 3D 物理仿真、状态/动作/奖励建模、动力学、目标追踪 |
| **深度学习** | 多层感知机(MLP)、前向传播、反向传播、ReLU、梯度下降（全部手写，不用框架） |
| **强化学习** | Q-Learning、DQN、ε-greedy 探索、经验回放、目标网络 |
| **可视化** | matplotlib 3D 场景、实时训练曲线、轨迹绘制 |
| **工程** | 模块化设计、requirements、.gitignore、README、Git 工作流 |

## 🏗️ 项目结构

```
robot-car-3d/
├── environment.py    # 3D 小车环境（物理仿真：小车、目标、边界、奖励）
├── neural_net.py     # 从零手写的神经网络（前向 + 反向传播）
├── dqn_agent.py      # DQN 智能体（经验回放、ε-greedy、目标网络）
├── train.py          # 训练主程序 + 实时 3D 可视化
├── requirements.txt  # 依赖清单
└── .gitignore        # Git 忽略规则
```

## 🚀 如何运行

```bash
# 1. 安装依赖（numpy、matplotlib）
pip install -r requirements.txt

# 2. 开始训练（会弹出实时 3D 可视化窗口）
python train.py
```

## 🎯 效果

- 左侧：**3D 场景** —— 蓝色小车实时追踪红色目标，轨迹逐步收敛
- 右侧：**训练曲线** —— 每个回合的累计奖励随学习不断提升

训练开始小车乱撞，几百回合后它会逐渐学会"朝目标方向走"，奖励曲线一路爬升。
